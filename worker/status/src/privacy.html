Privacy Policy

Last updated: 29 August 2026.

This policy covers gws-mcp, a personal, single-user application running on infrastructure at maybeit.work. It exists so its owner's own AI coding assistant can read and write the owner's own Google Workspace data. It has one user: the owner. It is not offered to anyone else, and no other person can sign in to it.

What data it accesses

Only Google Workspace data belonging to the Google account that grants it access, and only through Google's own APIs: Gmail, Calendar, Drive, Docs, Sheets, Slides, Forms, Tasks, Chat, Contacts and Apps Script. It accesses that data only while carrying out a request the owner has made.

Where the data goes

Requests are served by software running on the owner's own rented server. The OAuth refresh token Google issues is stored on that server's disk and nowhere else. Data fetched from Google is returned to the owner and is not written to any database, log store or analytics service maintained for this purpose.

What is never done with it

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is never sold, never transferred to third parties except as required to provide this application to its owner, never used for advertising, and never used to train generalised machine-learning models.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. Revoking invalidates the stored token immediately. To have the stored token deleted from the server as well, use the contact address below.
